# Task 01 – Loan EMI Calculator

## Objective

Develop a program to calculate the monthly installment (EMI)
for a loan using the given formula.

## Features

- Accept principal amount
- Accept monthly interest rate
- Accept loan tenure
- Calculate monthly EMI
- Display formatted results
- Validate user inputs

## Formula

EMI = P × r × (1+r)^n / ((1+r)^n - 1)

Where:

- P = Principal amount
- r = Monthly interest rate
- n = Number of months

## Technologies

- Python

## How to Run

```bash
python emi_calculator.py
